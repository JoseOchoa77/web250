# Start here — WEB-250 Assignment 12 tutorial

1. Read `docs/asgn12_setup.md`.
2. Put the `asgn12` and `asgn12_sandbox` folders beside one another in your existing `web250` folder.
3. Run `composer install` inside `asgn12`, create its `.env`, and verify the starting checkpoint.
4. Follow `docs/asgn12_tutorial.md`. It supplies all seven replacement blocks and a checkpoint after each one.
5. Use the two sandboxes whenever you want practice. They are optional, ungraded, and not submitted.
6. Complete your application's README, test the webhost, and submit the two links in Moodle.

The starter is intentionally unfinished only at T01–T07. Its login, registration, logout, and Bird features already work after setup. Admin pages initially deny access until T01; later admin methods display their stated temporary limitations until completed.

Keep your earlier assignments. If you already have an `asgn12`, save that work before installing this new starter. Use the supplied files together instead of mixing versions.
