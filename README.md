## Concept Check
### 1. Static Property vs Constant
Static properties are able to be changed, but its value is shared in existing and new instances of the same class. 
Constants always store the same value(s)
### 2. Constructor `$args` Array
The constructor enables a class to assign properties when initializing an new instance of a class.
The `$args` Array is a parameter that inputs an array so that the constructor can separate the array and assign to class variables.
### 3. Public vs Protected
Public properties are able to be accessed anywhere within a class and out.
Protected properties can only be accessed from withing the class or inherited class children.
