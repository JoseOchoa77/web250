# WEB 250 - Salamander CRUD Sandbox Starter

This is the ungraded practice starter for asgn10.

## Before the exercises

1. Import `sql/crud_salamanders.sql` into `wnc_salamanders`.
2. Copy `private/db_credentials.example.php` to `private/db_credentials.php`.
3. Enter your local database settings.
4. Open `public/salamanders.php`.
5. Confirm the table and Create Salamander page work.

Then follow the two sandbox sections in `asgn10_update_delete_bird.md`:

1. Update a Salamander.
2. Delete a Salamander with confirmation.

The sandbox is practice only and is not submitted for points.
